# IPTV Online — браузерный плеер плейлистов

Простой сайт без установки: открываете в браузере, загружаете M3U-плейлист (по ссылке или файлом) и смотрите каналы.
Сделан для тестирования бесплатных открытых плейлистов.

**Сайт:** https://ronis759.github.io/IPTV-online/

---

## Что умеет

- Загрузка плейлиста **по ссылке** или **файлом** (`.m3u`, `.m3u8`, `.txt`), в том числе перетаскиванием.
- Разбор стандартных тегов: `#EXTINF`, `tvg-logo`, `tvg-name`, `group-title`, `#EXTGRP`, `#EXTVLCOPT`, `#KODIPROP`.
- Список каналов с логотипами, поиском и фильтром по группам.
- Плеер: HLS (`.m3u8`) через hls.js, MPEG-TS (`.ts`) через mpegts.js, обычные `.mp4`/`.webm` — средствами браузера.
- Выбор качества, если поток отдаёт несколько вариантов.
- Избранное (звёздочка), переживает перезагрузку страницы.
- Сохранение плейлистов и кэша каналов в браузере — при следующем открытии список появляется сразу.
- Кнопки: пауза, полный экран, картинка в картинке, перезапуск потока, копирование ссылки.
- Горячие клавиши: `Пробел` — пауза, `F` — полный экран, `M` — звук, `/` — поиск, `↑`/`↓` — громкость.

## Как пользоваться

1. Откройте сайт.
2. Нажмите **«Плейлисты»**.
3. Вставьте ссылку на M3U-плейлист и нажмите **«Загрузить»** — или перетащите файл плейлиста в окно.
4. Выберите канал в списке слева.

Для быстрой проверки в окне есть готовые кнопки с открытыми списками [iptv-org](https://github.com/iptv-org/iptv) (Россия, Украина, Беларусь, Казахстан, Кино, Весь мир).

## Ограничения (важно)

- **CORS.** Многие бесплатные серверы не разрешают браузеру забирать плейлист или видео с другого сайта. Тогда канал не откроется. В настройках есть переключатель **CORS-прокси** — он помогает загрузить сам плейлист, но не гарантирует, что откроется видео.
- **http-потоки на https-сайте.** GitHub Pages работает по `https://`, а браузеры блокируют `http://` видео на таких страницах (mixed content). Такие каналы откроются только при локальном запуске сайта (`http://localhost`).
- **Форматы.** Браузер не умеет `rtsp://`, `udp://`, `mms://` — такие каналы при загрузке пропускаются.
- **DRM.** Защищённые потоки не поддерживаются.
- **Мёртвые ссылки.** Бесплатные плейлисты часто «гниют»: часть каналов просто не работает — это нормально для тестов.
- Сайт ничего не хранит на сервере: плейлисты, избранное и настройки лежат только в вашем браузере (`localStorage`).

## Запуск на компьютере

Нужен любой локальный веб-сервер (из-за ES-модулей открытие файла двойным щелчком не сработает).

```powershell
cd E:\OpenCode\IPTV-online
npx serve .
```

Или:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:3000` (у `serve`) или `http://localhost:8080`.

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source:** `Deploy from a branch`, **Branch:** `main`, папка `/ (root)`.
3. **Save**. Через 1–2 минуты сайт будет доступен по адресу
   https://ronis759.github.io/IPTV-online/

Обновление сайта — обычный `git push` в `main`.

## Структура

```
index.html              разметка страницы
assets/css/app.css      оформление
assets/js/app.js        логика интерфейса
assets/js/m3u.js        разбор M3U-плейлистов
assets/js/player.js     воспроизведение (HLS / MPEG-TS / native)
assets/js/store.js      localStorage: плейлисты, избранное, настройки
assets/vendor/          hls.js и mpegts.js (локальные копии, без CDN)
.nojekyll               отключает обработку Jekyll на GitHub Pages
```

## Технические решения

- Без сборки и зависимостей: чистые HTML/CSS/JS (ES-модули), работает на GitHub Pages как есть.
- hls.js и mpegts.js лежат локально в `assets/vendor`, поэтому сайт не зависит от доступности CDN.
- Плейлисты кэшируются в `localStorage` (до ~2,5 МБ на плейлист), чтобы список каналов открывался мгновенно.
- Разметка списка строится порциями по 250 каналов — большие списки (10 000+) не подвешивают страницу.
